## 一、本版本新增能力（4 项特性 + 1 项重大修复）

| # | 特性 | 说明 | 关键模块 |
|---|---|---|---|
| 1 | **机器码/硬件指纹绑定** | 防授权码多机共用；`SHA256(指纹) → HMAC-SHA256(app_secret)` 双层摘要；`machine_limit` 上限控制，自动绑定，超限返 2012 | `MachineService`、`VerifyService::validateMachine`、`machines.php` |
| 2 | **Python SDK** | 与 PHP SDK 功能对等；纯标准库（urllib/hashlib/hmac），零第三方依赖；936 行 | `sdk/dcai_client.py` |
| 3 | **试用模式 Trial** | 产品开放自助申请 → 一键生成试用授权码（source=3），试用期内视同正式授权；SDK 可感知剩余天数 | `StoreService::applyTrial`、`shop/trial.php`、`VerifyService::trialStatus` |
| 4 | **离线激活** | 内网/断网场景；RSA-SHA256 签名激活文件；后台导入签发 + API 在线签发双途径，产物一致；SDK `verify()` 优先本地离线授权 | `OfflineActivationService`、`offline.php`、`offline_activate.php` |
| 5 | **沙箱降级模式（重大修复）** | 宝塔默认 `disable_functions` 禁用 `proc_open` 曾导致远程模块 3003 崩溃；现自动降级为进程内命名空间沙箱（危险函数 stub + tick 超时），调用方无感 | `core/Sandbox.php` 双模式 |

## 三、数据库变更（install/migrate_v1.3.php，幂等）

- `licenses`：+`machine_limit`（默认 1）、+`trial_days`（默认 0）、`source`（3=试用）
- `products`：+`trial_enabled`、+`trial_days`
- `instances`：+`machine_code`
- 新表：`machine_bindings`（唯一键 license_id+machine_code）、`offline_activations`（唯一键 request_id+machine_code）

## 四、新增 API

| 接口 | 鉴权 | 说明 |
|---|---|---|
| `POST /offline/request` | app_secret 公开签名 | 在线签发离线激活文件 |
| `POST /offline/verify` | app_secret 公开签名 | 校验激活文件有效性 |

新增错误码：`2011 机器未绑定`、`2012 绑定机器数已达上限`、`5001 离线激活文件无效`。
