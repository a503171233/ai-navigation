三、发现并修复的问题（3 项，全部修复）

🔴 BUG 1：导航分组全部展开（核心缺陷）

服务端 header.php 输出的是 HTML 属性 hidden（<div class="nav-group-body" hidden>），而 CSS/JS 操作的是 class .hidden。类选择器永远不匹配属性，导致初始 6 个分组全部展开。

修复：服务端统一改为输出 class="nav-group-body hidden"，与 CSS/JS 约定一致。

🟡 BUG 2：折叠菜单链接仍可被 Tab 聚焦（无障碍）

折叠状态仅用 opacity:0; pointer-events:none，键盘用户仍可 Tab 到不可见的「登录/注册」链接。

修复：增加 visibility:hidden，并设 transition: visibility 0s linear（展开立即可见、收起延迟到动画结束），兼顾动画与键盘可达性。

🟡 BUG 3：商城二级导航/移动端菜单交互失效

shop.js 是同步 IIFE，在 <head> 同步执行时 DOM 尚未就绪，#shopMenuBtn / .nav-group 均查不到，事件从未绑定。

修复：<script defer>，脚本延迟到 DOM 解析完成后执行。
